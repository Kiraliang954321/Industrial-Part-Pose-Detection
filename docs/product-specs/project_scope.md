# 项目范围：传送带零件正反面与平面姿态

## 目标与现状

在固定俯视或近俯视相机、低成本照明条件下，探索从传送带单帧图像定位同类零件、判别**可见面** `front` / `back`、估计图像平面内无方向长轴姿态。课堂原型，非生产系统；不得用于安全联锁或设备控制。数据集能力、正反面可辨性、准确率、帧率和现场可靠性均**尚未验证**，须通过采集与审计确认，不能预设可行。

## Phase 1 冻结范围

- 仅以官方 Ultralytics `yolo26n-obb.pt` 为**单模型 OBB** 预训练基线及未来微调起点；本阶段建立可复现的运行脚手架、输入/输出约定、采集/标注规范和数据审计，不进行长时训练，不引入 Seg。
- 用有权使用的单帧测试图、固定相机与照明配置记录、传送带 ROI 验证环境及 OBB 输出可读性。预训练类别不等同于本项目的 `front` / `back`；烟测不证明任务精度。无测试图时先记录缺口，不虚构结果。
- ROI 只限定观测范围；以同一图像坐标系记录 ROI 顶点及标注，框中心在 ROI 内才视为候选；边界与遮挡样本须人工复核。跟踪、跨帧 ID、决策区触发和单件决策属于后续集成，不是本阶段交付。
- `front` / `back` 必须由人工可见面判据标注，不能由角度推断；不确定的样本不强行标注。长轴角度按图像水平轴 `θ ∈ [0°, 180°)` 表示，`θ` 与 `θ + 180°` 等价，不表达头尾方向；近方形或遮挡导致轴不稳定时标记为不可评估。

## 数据审计与验收

1. 形成采集清单：相机视角、照明、分辨率、图像来源/使用权、传送带 ROI 与其版本；覆盖不同可见面、旋转、位置、边界、遮挡等场景，并记录缺口。数据存在与能力均须实际审计，不可凭计划视为已满足。
2. 形成标注规范与审计记录：按可见面证据核查类别、OBB 四角/长轴、模 180° 姿态、无从判别时的处理、ROI 边界样本；明确同一坐标系及裁切/缩放变换。抽查分歧样本并记录修订，而不是把模糊样本算作正确。
3. 按采集序列隔离将来训练、验证和测试数据，核查近重复与数据泄漏、类别/姿态覆盖和难例；审计不通过时补拍或重标，不训练，也不报告任务指标。审计通过仅允许另行启动微调及独立评估，**不等于模型已达标**。
4. 保留烟测运行记录（权重来源/校验、Ultralytics/Python 版本、设备、输入尺寸、参数、ROI 版本与可视化/输出检查）；若没有帧或环境则明确记录未运行。Phase 1 的验收是规范、记录及基线脚手架可检查，不以预填准确率或实时 FPS 验收。
