# H1：夹持后视觉复核与螺丝预插入

日期：2026-10-31。用户同意按 ADR-0003 推进，并选择“螺丝对孔预插入”，不要求本轮模拟完整锁付。

状态：**首轮 H1 开发、训练、校准及冻结后独立仿真评价完成。** 本轮所有工位尺寸和阈值均为代理仿真开发参数。真实对象、真实公差和正式门禁不因此冻结。

## 本轮目标与设计

1. 在已知上料窝位进行物理夹取，移至固定检测姿态；先确认实际视野，不复用桌面模型成绩。
2. 使用两个正交固定 RGB 视角预测头/尾二维点，结合固定标定三角化三维端点。输出位置和有向轴线；对称轴绕轴角不估计，不称为完整 6D。
3. 采集以完整抓取 episode 为组的夹持后开发数据，验证既有模型，再按需要训练独立模型；不把同一抓取的两路图像或外观变体拆到不同 split。
4. 检查单件、头端朝上、轴线、视图一致性与夹爪下方露出长度。许可绑定 grasp ID、夹持 epoch、图像/机器人位姿时刻和有效期；重抓/松夹/过期/重复使用必须拒绝。
5. 依据预测端点相对实际 TCP 的偏差做目标补偿，进入真实有孔的导向座，达到预插入深度后仍保持夹持。插入过程读取模拟腕部力传感反馈，结果由独立 GT 评价。

首轮导向座采用约 10 mm 孔径配合 6 mm 代理杆体，目标预插入深度约 8 mm，用于验证视觉门控与动作衔接，不代表真实螺纹孔配合。孔的碰撞几何须实际留空，不能用填实的凸包冒充孔。旧代理仍没有真实螺纹啮合。

检测 TCP 采用 `(-0.10,0,0.25)` m，工具局部 X 轴沿世界 +Z，工具朝向绕世界 Z 轴转 -30°，避免 Panda 第七关节贴近限位。两路正交相机随该布局设置，工作距离约 0.30 m、640×640、垂直视场角 30°。导向孔中心 `(-0.10,0.10)` m、孔口高度 0.12 m。机器人真实关节位姿可参与坐标转换，对象真值不得参与视觉补偿或许可。

开发场景包括正常、反向、露出不足、可补偿轴向偏移、倾斜/呈现偏差、空抓和图像故障等适用情形；标签以实际物理状态为准，不能按场景名称强行填写成功或失败。首轮不承诺多料、执行中所有滑移或未知零件识别。

## 完成与证据要求

- 保存资产/代码/相机/数据/权重来源、分组划分、模型训练与校准记录。
- 视觉组仅使用图像预测、固定标定、机器人关节/TCP 反馈和明确的几何先验；GT 仅用于训练标注、参考分支和结果评分。
- 许可通过与预插入成功分别计数。预插入需检查实际深度、径向偏差、保持状态、力限与穿透；末端到位不能替代插入验证。
- 校准后冻结再评价新 episode；错误、拒绝和不适用自由度保留统计分母，比例给 x/n 与置信区间。
- M4/L1 已冻结源码和协议保持可复现；新增代码放在独立 `held/` 命名空间。训练用时设上限，先验证小批链路再扩大。

## 保留边界

本轮是预插入而非旋转起扣/拧紧，不输出锁付质量结论。单次检查不能保证随后绝不滑移；软件许可失效条件和可获得的夹爪反馈须明确，未覆盖的滑移仍记录为限制。真实传感器、工艺参数与实体执行器继续在本轮范围外。

## 实现与运行入口

新增模块均位于 `src/yolo_conveyor/held/`：`scene.py` 建立工位，`control.py` 规划与执行，`data.py` 生成/审计夹持图像，`training.py` 独立微调，`geometry.py` 三角化与预测补偿，`gate.py` 判定与单次许可，`runtime.py` 编排，`evaluation.py` 独立物理评分，`protocol.py` 冻结输入，`video.py` 记录实际物理渲染。旧 M3/M4/L1 源码不改动。

实际夹取后正常螺丝约有 4.3° 初始倾斜；H1 先测量并修正它，不能把“初始小于 3°”当默认门槛。开发许可接受小于 7.5° 的可测倾斜，独立 GT 包络为 8°；插入终态要求小于 3°。露出长度许可为 20–28 mm，独立 GT 为 19–29 mm，保留边界拒绝区。尺寸只适用于当前代理与薄夹指。

预插入采用 1 mm 级轴向路点，从孔口上方 15 mm 进入至下方 8 mm。腕部力/力矩以预对齐停稳时的读数为基线；开发保护限为增量 2 N / 0.2 Nm，触发后闭爪保位。原始传感值包含夹具自重等效项，不能直接拿绝对 2 N 判碰撞。许可时效按仿真时钟计算，尚不是实体设备安全联锁。

```powershell
.\.venv\Scripts\python.exe scripts/generate_held_inspection.py --assets data/robot-assets/panda-a662de6 --output data/held-inspection/<new-name>
.\.venv\Scripts\python.exe scripts/train_held_inspection.py --dataset data/held-inspection/<dataset> --initial-weights runs/screw-orientation/20261031-development-train-v2/fit/weights/best.pt --output runs/screw-orientation/<new-training>
.\.venv\Scripts\python.exe scripts/run_held_inspection.py --assets data/robot-assets/panda-a662de6 --weights runs/screw-orientation/<training>/fit/weights/best.pt --output runs/screw-orientation/<new-calibration> --mode calibration --seed 61000 --episodes 24
.\.venv\Scripts\python.exe scripts/freeze_held_inspection.py --training runs/screw-orientation/<training> --calibration runs/screw-orientation/<calibration> --output docs/data/<new-protocol>.json
.\.venv\Scripts\python.exe scripts/run_held_inspection.py --assets data/robot-assets/panda-a662de6 --weights runs/screw-orientation/<training>/fit/weights/best.pt --output runs/screw-orientation/<new-evaluation> --mode evaluate --protocol docs/data/<protocol>.json --seed 71000 --episodes 24 --record-first 4
```

每次必须使用新输出目录。训练数据按完整抓取 episode 分组，两视角/外观变体不是独立试验；PNG 字节重复时整对省略并记录，不靠添加噪声伪造独立性。独立评价保留正常、反向、短露出、长露出、倾斜、空抓、单相机黑屏及许可过期八类，各类数量均衡，不代表生产比例。许可过期是检查后注入的故障，单独统计许可拒绝，不冒充视觉拒绝。

- 初始模型：M3 两关键点权重，SHA-256 `0a29b8c5660d62cb19b84bf2cc0805e1c3b3ed2fb2e7478dc80813ab2f1e155a`。原桌面模型在夹持视图中混淆夹爪结构，不能直接复用其成绩。
- 训练：`runs/screw-orientation/20261031-h1-train-v1`，640 px / batch 16 / CUDA BF16 / AdamW，约 632.9 s。验证指标趋稳后主动提前结束，日志包含 6 个完整 epoch 及第 7 个 epoch 的 25/100 batch。**原始 `training-summary.json` 的 `actual_epochs: 7` 是 CSV 日志行数，不表示 7 个完整 epoch**；`training-termination-note.json` 保存停止说明、逐轮 batch 数和原始日志哈希，未改写原报告。后续训练器已区分完整轮数和日志轮数。
- 选定权重：上述训练目录 `fit/weights/best.pt`，SHA-256 `e78fc24c4dd5b758aa0646e8da7ec8b7ba251f382ac327c17dcf85725903cb03`。开发 Val pose mAP50–95 为 0.995；它只用于选模，不能作为插入成功率。
- 第一轮校准 `20261031-h1-calibration-v1` 使用 1 mm 视线间隙 / 2.5 px 重投影阈值，正常夹持出现过度拒绝；全部原始结果保留。依据校准图像及独立几何误差，最终选择 **1.5 mm / 3 px**，不改变终态成功容差。
- 第二轮校准 `20261031-h1-calibration-v2` 重用校准种子 61000–61023，24 次中 12 PASS / 6 REJECT / 6 UNCERTAIN。3 次 PASS 因随后注入许可过期而未执行，剩余 9/9 预插入成功；非合规件误放行 0/9。三次黑屏属于物理合规但视觉无法判定，计入合规未通过，单独按场景分层。

`tilted` 指上料时增加平面偏角，抓取过程会自定心；不能按这个场景名宣称覆盖了夹持后大倾角。实际轴向误差和 GT 以物理终态测量为准。导向孔通过中心/孔壁射线核验，孔中心穿过环形墙直到下方底板，孔壁射线命中楔形碰撞体；不是渲染出来的假孔。GT 参考分支只用于动作可行性开发，未给视觉分支提供端点。

## 冻结后的独立结果

运行目录：`runs/screw-orientation/20261031-h1-evaluation-v1`。24 个新 episode，种子 71000–71023，结果未用于阈值/模型调参。11 PASS / 6 REJECT / 7 UNCERTAIN；其中 3 次视觉 PASS 在后续注入过期故障后被许可层阻止，实际 8 次进入预插入，8 次通过独立物理评分。

| 场景 | 次数 | 检测与动作结果 |
| --- | ---: | --- |
| 正常夹持 | 3 | 2 PASS 并预插入成功；1 因双视图不一致 UNCERTAIN 留件 |
| 头尾反向 | 3 | 3 REJECT，不插入 |
| 露出不足 | 3 | 3 REJECT，不插入 |
| 可补偿的较长露出 | 3 | 3 PASS，3 次预插入成功 |
| 上料平面偏角 | 3 | 实际夹持后均在修正包络内，3 PASS，3 次预插入成功 |
| 空抓 | 3 | 3 UNCERTAIN，不插入 |
| 单相机黑屏 | 3 | 3 UNCERTAIN，不插入 |
| 许可过期 | 3 | 检测 PASS，消费许可时全部拒绝，不插入 |

- **Wrong Accept：0/9，Wilson 95% CI [0%, 29.91%]。** 小样本上界很宽，不能据此声称生产误放行率足够低。
- 实际尝试后的预插入成功 **8/8，95% CI [67.56%, 100%]**；相对于视觉 PASS 为 **8/11**，相对于全部故障加重场景为 **8/24**，三个分母不可互换。
- 物理合规但检测未通过 **4/15**：其中 3 次是黑屏故障，1 次是正常场景的一致性拒绝。普通合规、有图像且无许可故障的 9 次中，8 次放行并成功，1 次保守拒绝。
- 8 次成功终态：实际深度 **7.226–7.811 mm**（目标 8 mm，容差 ±1.5 mm），尖端径向误差 **0.565–0.732 mm**，轴线倾斜 **0.798–1.309°**，均保持双侧夹持。最大软接触穿透 **0.167 mm**；全 24 次无已定义的机械臂自碰撞/台面/导向座非法碰撞。
- 17 次有效双视图估计（含明确拒绝件）的尖端三维误差 P95 **1.636 mm**、轴向误差 P95 **1.304°**。丢失/不一致/故障拒绝不混入这个条件分母。
- 双视图推理 P95 **127.0 ms**；端到端本机墙钟 P95 **15.57 s**，含仿真、图像/日志和首四段录制开销；仿真时钟周期 P95 **41.81 s**，含注入的 30.1 s 许可等待。三者均不能直接换算真实整线产能。连续上下料/回程/恢复未实现，吞吐未测。

原始 `inspection.json` 保存两路输入哈希、预测、固定标定、实际 TCP、夹爪读数和时间；`wrench-trace.json` 保存 10 ms 间隔传感记录（保护检查在每个 1 ms 仿真步进行）；每次 `result.json` 保存独立 GT 和物理结果。`artifact-hashes.json` 的 **243 个文件**均重新核验通过，协议/权重/源码无漂移。
