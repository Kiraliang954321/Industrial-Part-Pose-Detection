# A2：带定位结构零件的连续三维朝向

日期：2026-11-01。用户明确要求指定空间方向和绕自身轴角，已确认按此方向开发。A1 六类判定保留，A2 不继承其姿态精度成绩。

## 契约与方案

- 轴承采用外圈带贯通定位缺口的项目自建定制代理，齿轮采用带贯通键槽的定制代理；它们不是原 F608ZZ / SB1-2040 标准件。定位结构用真实几何形成，没有色标。轴承测量的是外圈，内圈自由转动不作为外圈姿态。
- 首轮固定检测工位使用三个已标定 RGB 视角，预测孔口中心与定位结构四个角点，跨视角三角化并拟合刚体旋转。估计接口只收图像预测、标定和已知几何，禁止读取仿真对象真值或机器人展示角。
- 连续变化范围先验证朝上轴线、约 0–30° 倾斜、任意方位和 0–360° 绕轴角；不宣称覆盖整个 SO(3) 或任意遮挡。
- 目标由工位坐标系的倾角、方位角、绕轴角配置。比较轴向角误差、绕轴误差及整体旋转误差，使用开发容差和拒绝区；不把每个角度离散成类别。
- 先完成观测、模型、目标比较与独立评价。本轮不沿用固定动作冒充按预测姿态自动纠正，也不将求解中的平移当作已验证的装配定位精度。
- 按完整物理抓取隔离 Train/Val/Calibration/Evaluation；参考数据仅用于监督和独立评分。对称无定位结构对象、图像故障单列可测性检查。

状态：**连续角度测量、目标比较的 A2 初版及冻结后独立评价完成；当前可测覆盖率 55%，尚未达到稳定全覆盖。** 真实型号/CAD、标定、公差与正式门禁仍未冻结/CLOSED；仅验证定制代理仿真。

## 坐标与可配置目标

[datum_pose_targets_v1.json](../../data/datum_pose_targets_v1.json)给出目标：倾角、方位角、绕轴角以及各自的轴向/绕轴容差和拒绝区。坐标轴与仿真机器人基座平行。先用从世界 +Z 到目标轴线的最小旋转运输世界 +X，再绕局部 +Z 旋转定义绕轴角；不混同于未声明顺序的欧拉角。

数值输出包括单位轴线、完整旋转矩阵、倾角/方位/绕轴角。倾角小于 1° 时只将显示方位角标为不适用，轴向比较仍用单位向量夹角。绕轴误差先对齐两根轴线，再比较径向基准，正确处理 359°/1° 的 2°差值。模板初值拟合后使用实际图像重投影误差优化旋转和平移；平移是求解辅助量，不作为已验证装配位置精度。

首轮配置含四个目标，覆盖不同倾角/方位/绕轴角及 359°环绕边界。默认轴向和绕轴容差均为 10°，4° 为开发拒绝区：两项均小于等于 6° 才 PASS；任一大于 14° 明确拒绝；中间留件。图像或几何证据不足也留件。这不是实体工艺容差。

## 数据与开发记录

- 原始数据：`data/datum-pose/20261101-development-v1`，Train 200 次物理抓取 / 600 张图，Val 64 次 / 192 张图。每种零件 Train 含 80 次带定位结构、12 次无定位结构、8 次空抓；Val 含 24/4/4 次。三视角按完整抓取分组。
- 姿态在物理夹取后通过机器人展示动作变化，初始绕轴角独立随机。实际姿态由仿真测量只作标签/评分；同一机器人展示方向下，零件绕轴角可以不同。缺口/键槽不是彩色标记。
- 对称无定位结构样本的唯一绕轴角不可判定，作为 `INDETERMINATE` 单列；不把仿真内部坐标轴当作这些样本可测的真实方向。
- 全幅模型的中间权重在 Val 几何检查中未获得可靠姿态，相关结果保留于 `20261101-interim-val-v1`；不能用其 mAP 作为角度精度。
- 固定 ROI 为原图 `[160:480,160:480]`，放大至 640×640。派生图保持原始 episode 与 split；不增加独立样本数。预测坐标换回原图后使用原始标定；派生数据另保存变换后的内参。模型 checkpoint 记录 ROI，避免混用全幅和裁剪模型。
- 开发发现五关键点默认 OKS sigma 为 0.2，尺度较宽，导致 mAP 与所需像素精度不一致。精度微调数据 `20261101-roi-precise-v1` 明确设置 `kpt_oks_sigmas=[0.025]*5`，并沿用已完成的定位模型进行微调。旧数据、模型和失败诊断均保留，未用独立评价调参。
- 旋转求解器使用独立的 GT 像素参考检查，结果近数值零误差；该结果只验证几何公式，不是视觉模型成绩。

代码位于 `datum_pose/`；数据生成、ROI 派生、训练、Val 几何评价、目标工位运行和冻结入口分别是 `generate_datum_pose.py`、`crop_datum_pose.py`、`train_datum_pose.py`、`validate_datum_pose.py`、`run_datum_pose.py`、`freeze_datum_pose.py`。A1、H1/H2 旧源码不变。

## 最终测量方法与训练版本

单靠小范围定位角点的三维拟合仍出现轴向误差较大和大量拒绝，原始 `val-precise-v1`、`val-edge-probe-v1` 等诊断保留。最终使用：

1. YOLO26n-Pose 在固定 ROI 中预测两个定制对象及五个有序定位点，坐标换回原图。
2. 仅在 RGB 中进行局部角点细化和孔口椭圆拟合。缺口/键槽提供径向基准方向，孔口椭圆提供更大范围的平面观测。
3. 从椭圆及径向基准构造共面圆参考点，多视角三角化、刚体拟合、重投影优化；一致的视角子集可参与求解，竞争解接近但旋转明显不同则拒绝。重投影、射线和刚体残差门槛未被抬高。
4. 此圆参考构造包含当前工作距离下的弱透视近似，并假定正在观察已知朝上零件的下端孔口。构造点来自同一椭圆，不能被统计为多次独立测量。

最终模型：`runs/datum-pose/20261101-train-precise-v1/fit/weights/best.pt`，SHA-256 `7cbe908673310b64e16668d608d48e721b23e6fb30d7d254c75b42d019904ed3`。它在前序全幅/ROI 定位训练基础上，用显式 OKS sigma 0.025 再微调 10 个完整 epoch；不能写成从零仅训练 10 轮。前序与中断的初始化诊断均有独立目录，没有删除或覆盖。

最终开发 Val：`20261101-val-metrology-v1`。轴承 16/24 可测，条件平均轴向/绕轴误差 2.79°/1.57°；齿轮 22/24 可测，2.05°/1.14°。无定位结构和空抓共 16 次均未输出姿态。此为选型/开发证据，不替代下述新评价。

## 使用与交付

复制目标 JSON 到新文件后可修改角度与开发容差。模型输出连续旋转，不需要为每个新角度建立类别；但超出当前包络的目标必须扩展验证。修改已冻结目标文件会使原协议哈希校验失败，应使用新文件/新协议，不能覆写后继续沿用旧评价。

```powershell
.\.venv\Scripts\python.exe scripts/run_datum_pose.py --assets data/robot-assets/panda-a662de6 --weights runs/datum-pose/20261101-train-precise-v1/fit/weights/best.pt --targets docs/data/datum_pose_targets_v1.json --output runs/datum-pose/<new-run> --mode calibration --seed 161500
```

## 当前能力边界

本轮只完成**连续角度测量与目标判定**，未连接自动摆正或按新姿态装配；A1 的固定配方套轴不算 A2 的姿态闭环。当前前提是朝上轴线、倾角 0–30° 的夹持包络，反向、翻转、大倾角、未知 CAD 和真实金属反光未验证。尤其不能把这里的朝上孔口假设当作已经实现的正反防错；A1 的正反流程仍独立保留。

55% 的独立可测覆盖是明确限制，不能称为稳定识别任意姿态。后续若继续，应优先改善定位结构的可观测性与估计覆盖，而不是仅报告可用样本的低误差。任何利用本次评价改进的版本都必须使用新的独立评价样本。
