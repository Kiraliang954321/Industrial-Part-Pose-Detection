# A3：大倾角、翻转与视觉自动摆正后预定位

日期：2026-11-01。用户要求继续覆盖翻转、大倾角，并明确选择“自动摆正到指定朝向，再沿已有轴预定位”。状态：本轮实现、开发训练与冻结后仿真评价已完成；侧向覆盖与转运深度仍有限，真实门禁 CLOSED。

## 设计与实施顺序

1. 保留 A2 的源码、模型和评价。新实现放在 `pose_cell/`，不把扩大阈值当成翻转能力。
2. 验证高位料架上的侧向夹持，使翻转后的夹手仍位于孔轴侧方，避免从上方夹取后手掌挡住竖轴。执行通过真实关节控制与接触完成，不焊接零件、不重置持件位姿。
3. 三个上视和三个下视 RGB 观察位覆盖两端面；新模型区分对象和实际可见端面，预测孔中心/定位结构中心。正负端面的已知几何分别参与多视角 PnP 和重投影求解，不再假定孔口朝上。
4. 视觉测量后，以 `R_target @ R_measured.T` 及测得的工件相对 TCP 偏移生成校正。复拍验证后才允许沿已有竖轴预定位。估计器不得读取机器人展示角或对象 GT；机器人 FK 只供控制与坐标变换。
5. 先做物理可达性参考，再生成按物理抓取隔离的数据和训练；校准后冻结新评价。覆盖倾斜展示、世界轴线翻转、反向上料及无法判断/不可达情况，全部保留分母。

侧向夹持、料架和六视角均是仿真工位适配，不代表现有实体设备可直接使用。本轮仍是有间隙的预定位，不是压装、键槽啮合或斜轴工位装配。

## 输入与控制边界

- 两种定制代理沿用 A2 的外圈缺口轴承与带键槽锥形齿轮；模型不是对任意无特征轴承估计绕轴角。
- 六相机位于检测点上下斜视环，相机、CAD 尺寸和固定工位标定已知。网络给出端面候选与关键点，RGB 孔口边缘和静态外形决定几何一致性；图像输入不含渲染深度或分割真值。
- 初版 `corners_v1` 五点数据保留。后续 `centers_v2` 保持五输出槽位以继承模型，但只监督孔中心与结构中心；后三槽全部不可见、推理忽略，不能算五个独立几何观测。
- 训练抓取与验证抓取按 episode 隔离，六个视角同属一个 split。生成器对象 GT 仅用于监督；评价初始展示角和对象 GT 不传入估计器。实际机器人 FK 只用于把视觉对象位姿换算成工具目标。
- 校正最多三次，每次必须复拍。预测完整旋转误差 ≤7° 且轴线误差 ≤4° 才能预定位。独立 GT 判定 ≤10°/≤5°，并要求真实接触保持、径向偏差 ≤0.9 mm、3 mm 套入深度 ±1.2 mm、穿透 ≤0.5 mm 和无机器人固定环境碰撞。
- 对象重力有效；有限接触摩擦传递抓力，没有焊接、吸附或夹持过程重置对象位姿。相机推理期间仿真暂停，因此当前图像时效是仿真时间，不能当真实在线延迟保护。
- 大角度通过可达的抓手轴旋转扫描产生。覆盖 0/60/90/120/180° 展示及反向上料，不代表任意 SO(3) 机器人关节构型或复杂遮挡均可达。
- 本轮预定位目标为世界 +Z 轴，定位结构绕轴目标为 0°/30°/60°；初始上料周向角取对应目标加 12–25° 的扰动。训练覆盖 0–360° 周向角不等于当前机器人闭环已验证任意周向校正范围。

## 中心模型开发

- 数据：`data/pose-cell/20261101-centers-v1`，Train 1,392 图/232 抓取，Val 456 图/76 抓取。保留原随机大角度抓取，新增每对象 Train 20 / Val 6 次终态抓取。六视角仍按物理抓取整体分组，审计错误 0。
- 模型：`runs/pose-cell/20261101-train-centers-v1/fit/weights/best.pt`，SHA256 `d12fefc4565a20030cdbf752a4f31411be13eb77191f4dddf75d1385de9b6c3c`。继承第一轮 A3 权重，将角点输出的中心均值用于新中心槽初始化，16 epochs、batch 32、BF16、AdamW；全部 704 个批次完成，含末尾核验共 1,319.81 s，峰值 CUDA 分配 4,943,555,584 B。
- 选择规则仍为开发 Val pose fitness；几何与物理闭环成绩另报。`last.pt` 保留，不用独立评价选权重。
- `20261101-validation-centers-v1` 可测轴承 25/30、齿轮 20/30，但轴承有一次 177.25° 误判。该版不能用于自动动作验收；原始失败保留。
- 原候选排序过于强调圆孔一致的视角数量，而圆孔可能同时支持两个端面法向；现改为在至少两个独立相机支持的前提下，用重投影、静态外形与键槽边缘综合误差排序。对方向不同而图像成本接近的候选继续拒绝。
- 针对上述 Val 误判，将外形误差上限从 5 收紧为 **2 个原始像素**。这是开发侧工作点选择，会同时拒绝一部分遮挡较重的正确候选；冻结后的新评价不得据结果再次调整。
- Val 与运行时的几何工作图都是放大两倍的 640×640 固定 ROI；观测 JSON 的 `max_reprojection_px` / `profile_error_px` 以该工作图像素记录，换算原始图像像素需除以 2。阈值配置按原始像素定义，求解时统一乘以工作比例。
- `20261101-validation-centers-v2` 在收紧后可测轴承 22/30、齿轮 19/30，完整旋转误差均值 1.42°/1.97°，P95 2.78°/4.75°；负样本仍各 0/8 输出姿态。该 Val 是工作点开发材料，不能当独立最终表现。
- 第一轮物理校准 `20261101-calibration-v1` 发现几何预处理不一致：Val 使用放大固定 ROI，运行时使用原图边缘。保留部分校准记录及 `interruption-note.json`，不将该未完成批次冻结。运行时已统一为相同固定 ROI/相机内参变换，原始 RGB 和原图坐标预测仍留在证据中。
- 第二轮部分校准 `20261101-calibration-v2` 暴露了夹爪原有指面 `solref=0.02`、新增夹垫 `solref=0.003` 的不一致；零件实际接触原指面时出现较大软接触误差和下滑。`contact-diagnostic-v1` 将峰值定位到合爪阶段。降低夹紧量的参考试验 `grip-transfer-reference-v7` 未选用；最终保持闭爪命令 0.007 m，将所有指面接触参数统一为夹垫参数，摩擦、深度目标和验收限值保持原值，没有额外深度偏置。
- 单纯统一接触后，`contact-reference-v9` 暴露摆正后关节构型不利于转运的问题；控制器在检测位选择冗余关节构型时增加有界候选与后续转运运动学预检查，完成重构型后仍重新拍照。`contact-reference-v10` 的两个 180° 真值驱动物理参考均通过，轴承/齿轮最大穿透 0.160/0.076 mm；这不计入神经网络成功数。

## 运行入口与评价设计

`scripts/generate_pose_cell.py` 生成随机大角度物理抓取；`prepare_pose_cell_centers.py` 派生版本化中心监督并补终态；`train_pose_cell.py` 训练；`validate_pose_cell.py` 评价开发 Val 数值姿态；`run_pose_cell.py` 执行预测闭环；`freeze_pose_cell.py` 冻结完整校准、Val、模型、数据、资产、软件环境与源码哈希。

每个对象 8 个场景 ×3 个绕轴目标，共 24 次；两对象共 48 次。场景为直立、60°/90°/120°、180° 展示、反向上料、黑屏和无定位结构。校准种子从 201000 开始，齿轮加 100；冻结评价预留 211000/211100。黑屏计入全部有定位结构分母，另报告正常图像子集；无定位结构单独检查是否误触发校正/预定位。初始抓取和固定展示属于检测准备，不能误称为对无定位结构件执行了视觉校正。

所有有定位结构样本均保留在成功率分母；不能只用已经进入插入动作的样本给整体成功率。`preinsert_gt_aligned` 事后检查有定位结构、仍夹持及完整旋转/轴线角度门槛，不可用于实时否决或签发许可。`wrong_insertion_permission` 按这些条件统计，不替代执行后的深度和偏心验收。物理终态不合格继续记为失败，不能用旋转误差合格替代深度、偏心、保持和接触验收。
