## 当前基础与实施边界

历史二维链路和报告继续保留。新增螺丝代理 Train 2000 / Val 400 张、独立关键点入口与 Panda 2.5D 仿真闭环；尚无真实工业件正式数据或完整 6D 证据。新入口未继承瓶盖类别、颜色过滤或开发成绩。

S0–S4 是新增研究顺序，不表示 [V4.1 Phase 1](phase1_execution_plan.md)或 Phase 2–6 已通过验收。原协议未 FROZEN、Dataset V1 / Training Gate CLOSED 的状态继续保留。新任务先明确适用的二维条款和所需 3D 协议，再按相应门禁推进正式训练。

## 阶段计划

| 阶段 | 工作 | 完成条件与交付物 |
| --- | --- | --- |
| S0 任务定义 | 确认工业件、CAD、方向、相机和坐标规则 | 完成上述定义，记录待测值及协议适用关系 |
| S1 朝向基线 | 针对可观察的方向/头尾建立规则或特征方法，与学习方法对照 | 同输入和真值下的结果、失败样本、数据划分及运行投入；不以 OBB 角冒充 3D |
| S2 仿真数据 | 验证轻量单对象、单相机、机械臂/夹爪场景，生成带来源的监督材料 | 场景与资产版本、相机/姿态标签审计、配置和随机种子、未见场景、资源记录 |
| S3 闭环验证 | 预测经坐标变换与抓取偏置进入运动学/路径/碰撞检查，对照真值驱动组 | 抓取/放置成功数与分母、掉落/碰撞/不可达、延迟和失败归因 |
| S4 迁移与 6D | 独立实拍验证迁移；尺度、CAD、观测和真值满足时扩展完整 6D | 仿真与真实分层报告、平移/旋转或轴向误差、对称性处理及范围调整决定 |

S1 可先交付受约束平面朝向；完整 6D 不是首轮无条件承诺。动作策略学习是可选分支，另行定义状态、动作、奖励或示教数据，不能把运动学规划称为已经训练出的策略。

## 数据与评价清单

- [ ] 每个数据来源绑定对象、资产、尺度、坐标约定、相机、场景/episode、配置与随机种子。
- [ ] 仿真与真实分开，训练与测试按来源组隔离；保存未参与选模的场景/工况和最终保留材料。
- [ ] 仿真真值仅用于监督/评价；视觉预测组不得直接使用真值位姿驱动机械臂。
- [ ] 同任务比较相同观测、输入分辨率、真值、事件和计时规则；只在开发/校准侧选择阈值。
- [ ] 姿态评价说明尺度、单位、周期、对称性与不可判定；要求区分头尾时不把反向当作等价。
- [x] M4 仿真成功已检查双侧接触、提起保持、搬运、释放、落点、方向、落稳与碰撞/软穿透；无对象吸附或执行中位姿重置。
- [ ] 比例报告 `x/n` 与适用置信区间，零错误也报告上界；训练耗时、图像 FPS、仿真步频、端到端延迟及事件吞吐分别记录。
- [ ] 真实工位真值沿用 `CONFORMING / NONCONFORMING / INDETERMINATE` 的独立定义；`UNCERTAIN` 仍是系统决策，不变成训练类或人工真值。

## 平台与成本检查

本机已采用并验证 MuJoCo 3.17.0，M4 资产/控制设置和源文件哈希见[冻结开发协议](../../data/screw_m4_protocol_v1.json)。此前 PyBullet Windows wheel 与 Isaac Sim 显存条件的调研仍作选型依据；BlenderProc 等仅在新的真实性需求下另行引入。本轮不升级已有训练依赖，不把仿真参数当成真实参数冻结。

实施前核对本机资源与平台版本需求，分别记录引擎、CAD、机器人资产、纹理、权重和数据许可。成本包含建模、标定、数据、开发、算力、授权与真实验证；不沿用历史二维原型的新增硬件预算作为 3D 总价。
