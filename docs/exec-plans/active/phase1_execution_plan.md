# Phase 1 执行计划：单 OBB 基线与数据审计

状态：部分完成（基线脚手架与环境/集成验证已完成；真实数据审计与训练仍待执行）。以下已验证事实不构成模型质量或生产能力报告。范围见 [项目范围](../../product-specs/project_scope.md)，实现约定见 [基线设计](../../design-docs/phase1_obb_baseline.md)。

## 已完成：脚手架与环境验证

- 已建立 `pyproject.toml`、`src/`、`scripts/` 和 `tests/`：单帧 OBB 适配器、命令行入口、环境检查、数据审计脚本及自动化测试。项目安装使用 `python -m pip install -e ".[test,inference]"`。
- 本地 `.venv` 已安装 Ultralytics 8.4.165 和 pytest；13 个自动化测试通过，`compileall` 通过。项目适配器已加载官方 `yolo26n-obb.pt`，在 RTX 4060/CUDA 上对合成空白图像完成一次烟测推理。这只验证环境和推理集成；不证明工业准确率、FPS、`front`/`back` 识别效果或真实数据审计完成。

## 数据与实测记录：后续顺序

1. **待完成：固定观测约定。** 记录相机视角、照明、分辨率、合法图像来源、固定传送带 ROI 顶点及版本；明确 `front` / `back` 可见面判据和不可判别处理，制定 OBB 四角/图像坐标系/无方向长轴角度的标注规则。产物：采集与标注规范草案、缺口清单。
2. **待完成：采集与审计。** 按可见面、旋转、位置、照明、遮挡及 ROI 边界场景核查实际样本；按采集序列隔离将来训练/验证/测试，排查近重复、类别与角度覆盖及标注一致性。产物：数据审计记录、分歧/不确定样本清单与补拍/重标结论。能力仍视为未验证，直到完成审计；审计不过不训练。
3. **部分完成：单帧集成烟测。** 上述项目适配器与合成空白图像的烟测已完成；合法真实测试帧的本地运行记录仍待补齐（示例在仓库 `README.md`）。记录权重来源/校验、版本、设备、输入分辨率及命令参数，检查推理可运行及 OBB 输出可读，保留 ROI 过滤前的输出。若无真实帧，明确标记未运行及原因。产物：真实帧本地运行记录；预训练预测不构成 `front`/`back` 精度证据。不提交原图、权重或私有数据。
4. **待完成：核对范围。** 检查规范、审计结论和烟测记录的可追溯性，列出未解决缺口及下一阶段所需条件。只在审计通过后另行规划面向 `front` / `back` 的微调和独立评估；不在本 Phase 1 安排长时训练、Seg、跟踪或决策区运行时。任何准确率、角度误差或 FPS 均需实际测量后才能报告。

## 停止条件与边界

数据来源、可见面可判别性、OBB 标注/ROI 坐标或序列隔离无法核实，就标记风险并先修复数据；不要虚构通过的审计或模型性能。角度按模 180° 处理，近方形及重遮挡样本不强报姿态；不能从角度推断正反面。跨帧 ID、单件触发及靠近分拣时机的决策区仅为后续集成接口，非当前可交付能力。技术选择依据见 [ADR-0001](../../decisions/adr-0001-single-obb-baseline.md)。
