# ADR-0001：Phase 1 采用单个官方 OBB 基线

状态：已选定 Phase 1 方案（非实测性能结论）。

## 背景

课堂原型希望以固定相机和低成本照明在传送带图像中定位零件，判断可见面 `front` / `back`，估计图像平面内的长轴姿态。当前缺少已审计的数据及可报告的性能结果；不能从预训练类别推断本任务的正反面能力。Phase 1 的目标是可复现单帧基线脚手架及采集/标注/数据审计，而非生产部署。

## 决定

仅以官方 Ultralytics `yolo26n-obb.pt` 为单模型 OBB 预训练基线与未来微调起点，不在 Phase 1 增加 Seg 分支或长时训练。通过单帧输出检查类别、置信度及旋转框；仅在审计数据支持时，后续另行微调并独立评估 `front`/`back`。用人工核查的可见面标签表示正反面，不用 OBB 角度推断。将长轴方向约定为图像水平轴起算、模 180° 的 `θ ∈ [0°, 180°)`；近方形或轴不稳定时不强行评分。

## 取舍与后果

单模型 OBB 使输入、标注与输出契约集中，适合先审计可见面判据、旋转框与 ROI 坐标；它**不证明**模型准确、实时或能应对反光/遮挡。Seg 或多模型方案增加标注和集成范围，需在后续另行论证，当前不采用。固定传送带 ROI 只过滤观测区域（候选框中心在 ROI 内），不是跟踪或事件判定；跨帧 ID、决策区触发和单件一次决策留待后续集成。不得将烟测成功当成可用于控制的证据。
