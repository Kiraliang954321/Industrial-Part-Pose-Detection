# ADR-0003：夹持后检测与装配前复核主线

日期：2026-10-31。

状态：**工艺调研完成；用户已选择首轮“螺丝对孔预插入”，H1 开发、训练与冻结后独立仿真评价完成。真实验收条件尚未冻结。**

## 用户最新用途

机械臂先夹起零件，移动到固定高度/检测位置，由相机判断方向姿态是否满足要求，合格后再继续把零件装上。用户明确目前不确定它是否适合直接生产，要求先调研。

这与 L1“来料检测后分流”的观察阶段和目的不同。后续默认主线转为**抓取后复核、二次定位与装配前许可**；L1 保留为已完成的开发分支，不继续默认扩展连续输送线。

## 调研决定

- 工业技术手册存在相同类别的流程，故该用途值得研究；不能据此断言现有项目已可直接投产。依据与限制见[调研报告](../design-docs/held_part_inspection_assembly_research_20261031.md)。
- “固定高度”需具体化为受控检测姿态、工作距离、可见特征、光照及相机/机器人/工具标定关系。
- 检查可以是状态防错，也可以进一步测量并补偿工件相对夹爪的偏差。补偿只使用可观测的预测信息，不用对象 GT 补齐缺失自由度。
- 装配前通过与装配成功分开。螺丝锁付、轴承压装或齿轮套装需要各自的配合目标、工具、过程反馈与成功条件。
- 首轮“装上”已明确为对孔预插入，仍保持夹持；不认定为拧紧完成。实际型号/CAD 与真实配合公差仍待确定。

## 对既有工作与实施的影响

M3 的模型/审计基础、M4 的物理夹持、L1 的多帧事件思想可复用；现有视觉识别发生在抓取前，旧数据和成绩不能直接作为夹持后检测证据。已有 `screw_proxy_v0` 不具备真实螺纹啮合。

用户后续已授权按[H1 计划](../exec-plans/active/held_inspection_h1.md)推进开发与训练：先使用螺丝代理、两个固定 RGB 视角及真实留孔的导向座，验证视觉估计、夹持许可与物理预插入。真实 Experiment Protocol 与 Dataset/Training Gate 保持未冻结/CLOSED；实体执行机构仍在项目实施范围外。
