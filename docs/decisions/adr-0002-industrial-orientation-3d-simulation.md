## 已确认的方向

### 对象与检测目标

| 候选对象 | 可研究的检测目标 | 选型时必须确认 |
| --- | --- | --- |
| 轴承 | 可辨端面、轴线朝向、倾斜状态 | 具体型号的可见差异、反光与旋转对称性；不能把所有轴承统一视为可辨面或角度 N/A |
| 锥形齿轮 | 锥面、轴线、轮毂或键槽方向 | 重复齿的等价旋转、破对称特征是否可见、CAD 与实物尺度 |
| 螺丝 | 头尾、轴线、头部槽型相关方向 | 遮挡、细长结构与槽型对称周期；绕轴角未必唯一 |

尚未指定某一型号为正式 Part A/B，也不要求一次完成三类对象。首个对象优先选择方向特征明确、工艺需求可描述且能取得真实比例 CAD 的工业件；具体选择在 S0 确认。不能为了容易成功，在看到测试结果后临时更换对象或合格判据。

先验证工位需要且能够观察的朝向，再按条件扩展完整 6D 姿态：

- 朝向可以是头尾、轴线、端面或平面特征角，不自动包含空间位置。
- 完整 6D 姿态是 3D 平移 `t` 与 3D 旋转 `R`，需要尺度、相机模型、坐标约定和有效姿态真值。
- OBB 的图像旋转角不能直接当成空间姿态。对称对象按等价姿态或可观察自由度评价，不强造唯一绕轴角。
- 要求区分头尾时保留方向符号，不能用无方向长轴或绝对值隐藏 180° 翻转。

### 虚拟机械臂的职责

1. **视觉训练数据生成**：用工业件模型、相机与可控场景生成图像和姿态监督标签。
2. **视觉引导闭环验证**：将模型预测转到机器人基座坐标，结合抓取偏置、运动学、路径与碰撞检查，评价虚拟抓取或摆正。
3. **动作策略学习**：需要另行定义状态、动作、示教或奖励，列为后续可选分支，不作为首轮默认任务。

仿真真值用于监督和评价，不能直接冒充视觉预测。保留“真值驱动规划”参考组，与相同场景和规划器下的“视觉预测驱动规划”比较，区分感知失败与控制失败。仅到达坐标不等于成功抓取；穿透、吸附辅助或直接修改对象位姿须单独声明。

实体机械臂、PLC、安全联锁及生产执行机构仍不属于当前实施范围。

## 技术建议与待验证选择

| 建议 | 适用理由与条件 |
| --- | --- |
| PyBullet 作为轻量原型候选 | 先验证单对象、单相机和夹爪的小场景；速度与迁移效果尚待本机实测 |
| MuJoCo 作为备选 | 用于关节与接触物理、控制研究，需要适配模型与接口 |
| 按需引入 BlenderProc | 辅助生成更真实的离线图像，不等同于机器人控制训练平台 |
| Isaac Sim 作为额外资源方案 | 2026-10-28 核对的官方最低配置表列 32GB 内存、16GB 显存；当时本机约 8GB 显存，不默认承诺复杂场景可用，实施时重新核对版本需求 |
| 保留简单视觉与学习方法对照 | 规则、方向特征、关键点加 PnP，以及条件具备时的 RGB-D 方法按同一任务要求比较，不预设模型赢家 |

上述是调研建议，不代表已冻结平台、已安装环境或已验证性能。现有训练与预测入口绑定 `cap_a`、面类及黄色过滤，不能直接作为三类工业件的通用运行时；需要按新任务设计接口、配置与数据契约。

## 数据与证据边界

- 历史瓶盖素材、权重、开发指标、标注接受记录和演示保留为既有二维原型证据，不改写为工业件或 3D 结果。
- 新数据记录对象/CAD 版本和尺度、场景/episode、随机种子、相机内外参、坐标系、姿态与可见性、对称性及来源。现有面类/OBB sidecar 不自动成为 3D 监督格式。
- 新增 3D 字段、旋转表示、单位和评价容差须形成版本化协议，不把空间姿态直接写入现有二维 `angle` 语义。
- 仿真按独立场景、episode 与生成配置隔离训练、校准和未见测试；真实素材按独立采集会话划分。相邻帧、增强和同源派生图不计作独立证据。
- 感知误差、仿真闭环和真实域验证分层报告。仿真成功率不能当成实机可靠性，合成材料不能补填真实 Dataset V1 门禁。
- 阈值在开发/校准侧选择并冻结，Test/Final Holdout 不调参；缺少工艺与实物依据的参数保持待定，不预填精度或速度。
- 低成本按硬件、CAD、标定、数据、开发、换型、算力和授权的总投入比较。历史 100–280 元新增原型预算不是 3D 方案报价。
